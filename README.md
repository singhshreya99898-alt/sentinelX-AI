# SentinelX AI 🛡️

### AI-Based Activity Monitoring and Risk Analysis System

SentinelX AI is a cybersecurity-focused project designed to
monitor user activity and support security risk analysis.

## 🎯 Project Objective

The objective of SentinelX AI is to explore how activity
monitoring and risk analysis can help identify potentially
suspicious activities in a computer system.

## ✨ Project Features

- Activity monitoring interface
- User activity information
- Activity history
- Risk analysis project concept
- Web-based frontend and backend architecture

*Note: Features depend on the current implementation of the project.*

## 🛠️ Technology Stack

- Frontend: React.js and Vite
- Backend: Python
- API: FastAPI (if used in the current backend)
- Database: SQLite (if configured in the current version)
